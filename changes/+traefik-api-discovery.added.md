Discover hostnames from the Traefik REST API (`GET /api/http/routers`) with `DNSWEAVER_SOURCE_TRAEFIK_API_URL` (or `sources[].api.url` in YAML). The API reports the routers Traefik actually built, so containers that only get a router from a provider `defaultRule` are now covered, together with routers from every Traefik provider. Supports pagination, basic auth (`API_USERNAME` / `API_PASSWORD[_FILE]`), provider exclusion (`API_EXCLUDE_PROVIDERS`, default `internal`), `using` entrypoints and `API_POLL_INTERVAL`. An unreachable or failing API marks discovery incomplete so no records are deleted.
