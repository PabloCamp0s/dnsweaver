Discover hostnames from the Traefik REST API (`GET /api/http/routers`) with `DNSWEAVER_SOURCE_TRAEFIK_API_URL` (or `sources[].api.url` in YAML). The API reports the routers Traefik actually built, so containers that only get a router from a provider `defaultRule` are now covered, together with routers from every Traefik provider. Supports pagination, basic auth (`API_USERNAME` / `API_PASSWORD[_FILE]`), provider exclusion (`API_EXCLUDE_PROVIDERS`, default `internal`), `using` entrypoints and `API_POLL_INTERVAL`. An unreachable or failing API marks discovery incomplete so no records are deleted. The router list is requested in a single page and re-read until consistent if the server paginates, and a successful but suspicious answer (a provider that had routers reports none, or the list shrinks by more than half) keeps the previous hostnames for `API_DROP_GRACE` (default 5m) before removing them, and until Traefik has been running for `API_STARTUP_SETTLE` (default 60s, read from `/api/version`) its router list is not trusted, covering Traefik restarts where the API answers before its providers have loaded, including dnsweaver and Traefik restarting together.
